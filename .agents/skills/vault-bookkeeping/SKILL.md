# 볼트 장부정리

정식 볼트: `/Users/yejinkim/Library/Mobile Documents/iCloud~md~obsidian/Documents/study/`
원문 규칙: 볼트의 `📐 볼트 규칙.md` (이 스킬은 그 §3④~⑥·§6의 실행 절차 요약)

## ④ 복리 (의무 — 건너뛰면 볼트는 덧셈으로만 자란다)

1. 새 노트의 주제어로 볼트 전체를 Grep해서 닿는 기존 노트를 찾는다. kbap 백엔드 폴더만이 아니라 **기존 주제 전부**가 대상이다 (인증·보안 ↔ JWT 인증, 백엔드/페이징 ↔ 커서 페이징 spec kb-63, Expo & React Native ↔ API 소비 관점, Codex 작동원리 ↔ SpecKit 하네스 등).
2. 새 노트 → 기존 노트, 기존 노트 → 새 노트 **양방향**으로 링크를 건다. 기존 노트 수정 전 반드시 Read.
3. 기존 노트에 보강할 내용이 있으면 직접 갱신하고, 모순이면 `> [!warning] 모순` 콜아웃을 단다.

## ⑤ 홈 등록

- `🏠 홈.md`의 해당 주제 섹션(kbap 백엔드는 `### kbap 백엔드` — 없으면 신설)에 `- [[정확한 파일명]] — 한 줄 요약` 추가.
- **링크는 파일명과 글자까지 일치** — 등록 전에 실제 파일명을 ls로 확인한다 (2026-07-08 깨진 링크 사고).
- 공부 지도(`🗺️ kbap 백엔드 공부 지도`)가 있는 주제는 개별 노트를 홈에 전부 나열하지 않고 지도 경유로 등록해도 된다(Codex 작동원리 방식).

## ⑥ 작업 로그

`📜 작업 로그.md` 맨 아래 append (append-only, 기존 줄 수정 금지):
```
- [YYYY-MM-DD] ingest | kbap 백엔드 N단계: 노트 A·노트 B (요지)
- [YYYY-MM-DD] update | 복리: 갱신한 기존 노트와 내용 요지
```
동사: `setup`(구조) · `ingest`(새 노트) · `update`(기존 갱신) · `move` · `lint` · `fix`.

## 단계 마무리 린트 (§6 축약)

- [ ] 이번 단계 노트들의 `[[링크]]` ↔ 실제 파일명 전수 대조 (양쪽을 열어 글자 비교)
- [ ] 새 노트 중 인바운드 링크 0개(고아) 없는지 — 최소 공부 지도에서는 링크돼야 함
- [ ] 홈/지도 미등록 노트 없는지
- [ ] `상태: 진행중` 방치 없는지
- 결과를 로그에 `lint |`로 한 줄 남긴다.
