# 🗺️ Claude Code 작동원리 지도

> 출처: [shareAI-lab/learn-claude-code](https://github.com/shareAI-lab/learn-claude-code)
> — Claude Code 같은 AI 에이전트가 **내부에서 어떻게 돌아가는가**를 20개 레슨으로 가르치는 교육용 레포.
> 이 지도는 20개 레슨을 6묶음으로 정리한 **목차**예요. 순서대로 읽으면 큰 그림이 잡혀요.

---

## 0. 이 레포의 핵심 철학 (제일 중요)

> **"에이전트의 능력은 모델 훈련에서 나오지, 코드로 짜맞춘 워크플로우에서 나오는 게 아니다.
> 하네스(harness)는 탈것이고, 모델이 운전자다."**

- **하네스(harness)** = 모델 주변을 감싸는 운영 인프라 (루프, 도구, 권한, 메모리 등).
- 진짜 에이전트 = 잘 설계된 환경(하네스)에 배치된 **훈련된 모델**이지, 프롬프트를 엮은 워크플로우가 아니다.
- 이 20개 레슨은 결국 **"좋은 하네스를 어떻게 만드는가"** 를 하나씩 뜯어보는 것.
