# Obsidian 개념과 활용법 — 다음에도 쓰는 용

> 작성: 2026-07-02 · 맥락: 공부 노트를 이 폴더에 옵시디언으로 관리하기로 하고 정리.
> 목표: "옵시디언이 뭐고, 어떻게 쓰고, 왜 이렇게 쓰지?"를 나중의 나도 바로 재현.

---

## 0. 한 줄 요약
**옵시디언은 내 컴퓨터 폴더 안의 마크다운(`.md`) 파일들을 예쁘게 열어보고, 노트끼리
`[[링크]]`로 연결해 지식망을 만드는 설치형 앱이다.** 파일은 전부 내 것(로컬)이라 앱이
없어져도 텍스트로 남는다. 문서 작성은 클로드 코드가, 열어보기는 옵시디언이 담당.

---

## 1. 핵심 개념

| 구분 | 옵시디언 | 노션(비교용) |
|---|---|---|
| 저장 위치 | **내 컴퓨터 폴더** (로컬) | 회사 서버(클라우드) |
| 파일 형식 | 그냥 `.md` 텍스트 | 자체 포맷 |
| 종속(lock-in) | 없음 (메모장으로도 열림) | 있음 |
| 특기 | 노트 **연결·그래프** | 데이터베이스·협업 |
| 형태 | 설치형 앱 (웹 ✗) | 웹/앱 |
| 가격 | 개인 무료 | 부분 무료 |

**지원 플랫폼:** Mac / Windows / Linux / iOS / Android (**웹 버전은 없음**).
**유료(선택):** Sync(기기 동기화) · Publish(웹 공개). 안 써도 됨.

> 비유: 옵시디언 = "내 서재". 책(.md 파일)은 내 책장에 그대로 꽂혀 있고, 옵시디언은
> 그 책을 읽기 좋게 펼쳐주고 책끼리 실로 이어주는 도구. 노션 = "도서관 회원제"(책이 그쪽 소유).

---

## 2. 3대 핵심 개념 (이것만 알면 됨)

### 2-1. Vault (볼트) = 폴더 하나
옵시디언이 "볼트를 열어라"는 건 **내가 지정한 폴더를 열어라**는 뜻. 그 폴더 안의 모든
`.md`가 옵시디언 안에서 노트로 보임. (우리 볼트 = `study` 폴더)

### 2-2. 마크다운 = 글쓰기 문법
```markdown
# 큰 제목      ## 중간 제목
- 목록          1. 번호목록
**굵게**  *기울임*  `코드`
> 인용문
| 표 | 헤더 |
```

### 2-3. `[[내부 링크]]` = 옵시디언의 심장
- 글 쓰다 `[[` 치면 다른 노트 이름 자동완성 → 연결됨.
- 연결된 노트끼리 **그래프(지식 지도)** 로 시각화됨.
- **백링크**: A가 B를 링크하면, B에서도 "나를 링크한 노트: A"가 자동으로 보임.

---

## 3. 우리 볼트 구조와 규칙

```
study/  ← 볼트(=폴더)
├── 🏠 홈.md              ← 현관문(MOC). 모든 노트로 뻗어나가는 목차
├── _templates/          ← 새 노트용 양식 (앞에 _ 붙여 맨 위 정렬)
│   └── 📝 공부노트 템플릿.md
├── Obsidian/            ← 주제 폴더 (지금 이 노트)
└── Expo & React Native/ ← 주제 폴더
```

**우리 규칙:**
- 주제마다 **폴더 하나**. 노트는 그 안에.
- 모든 노트 맨 위에 **프론트매터**(`--- tags / 생성일 / 상태 ---`)로 분류.
- 새 노트 다 쓰면 **[[🏠 홈]]의 목록에 링크 한 줄 추가**.
- 파일 이름 = 노트 제목이니 **읽기 좋은 이름**으로 (대시 남발 ✗).

> [!note] MOC란?
> Map of Content = "목차 노트". 폴더 대신 **링크로 짜는 목차**. 우리의 [[🏠 홈]]이 바로 MOC.

---

## 4. 자주 쓰는 단축키 치트시트 (Mac)
```
Cmd + O            노트 이름으로 빠르게 열기
Cmd + E            편집 ↔ 미리보기 전환
Cmd + Shift + F    모든 노트 내용 통합 검색
Cmd + P            명령어 팔레트(뭐든 기능 검색)
Cmd + 클릭         링크를 새 패널로 열기
[[                 내부 링크 자동완성
```
> 왼쪽 사이드바 아이콘: 📄 파일 · 🔍 검색 · 🏷️ 태그 · ⚙️ 설정 · (그래프는 상단/명령어 팔레트에서)

## 5. 활용 팁 (공부 노트에 실제로 쓸 것)

- **콜아웃(예쁜 강조 박스):** 지금 이 문서의 파란/노란 박스들.
  ```markdown
  > [!tip] 팁 제목
  > 내용
  ```
  종류: `note` `tip` `info` `warning` `danger` `question` 등.
- **체크박스 할일:** `- [ ] 할일` → 미리보기에서 클릭 가능한 체크박스.
- **태그로 모아보기:** `tags: [expo]` → 사이드바 태그 클릭 시 같은 태그 노트 전부 모임.
- **그래프 뷰:** 노트가 쌓이면 연결망이 지도로 보임. "어떤 개념이 중심인지" 한눈에.
- **데일리 노트(선택):** 날짜별 노트 자동 생성 기능. 공부 일지 쓸 때 유용.

---

## 6. 클로드 코드 ↔ 옵시디언 분업 (핵심 워크플로우)

| 역할 | 담당 |
|---|---|
| 노트 **작성·수정·정리·링크 걸기** | **클로드 코드 (나)** |
| 노트 **열어보기·읽기·직접 편집** | **옵시디언 (앱)** |
| 뭘 만들지 지시 | **나(사용자)** |

**둘은 같은 폴더의 같은 파일을 봄** → 클로드가 파일 만들면 옵시디언에 바로 뜸(연동 설정 불필요).

> 실전: 새 주제가 생기면 클로드에게 **"OO 주제로 공부 노트 만들어줘"** → 템플릿대로
> 채우고 [[🏠 홈]]에 링크까지 걸어줌. 나는 옵시디언에서 열어보기만.

---

## 7. 용어집
- **Vault(볼트):** 옵시디언이 관리하는 최상위 폴더. = 내 노트 저장소.
- **마크다운(.md):** 기호로 서식을 주는 텍스트 문법.
- **내부 링크 `[[ ]]`:** 노트끼리 잇는 연결. 옵시디언의 핵심.
- **백링크:** 나를 링크한 노트 목록(자동 표시).
- **그래프 뷰:** 노트 연결망을 점·선 지도로 시각화.
- **MOC:** Map of Content. 링크로 짠 목차 노트(우리의 [[🏠 홈]]).
- **프론트매터:** 노트 맨 위 `--- ---` 사이의 메타정보(태그/날짜 등).
- **콜아웃:** `> [!tip]` 같은 강조 박스.
- **Sync / Publish:** 옵시디언 유료 부가서비스(동기화 / 웹공개). 선택.

---

## 8. 다음에 빠른 재현 체크리스트
1. 옵시디언 앱 설치 (개인 무료, [obsidian.md](https://obsidian.md)).
2. **Open folder as vault** → 공부 폴더 지정.
3. [[🏠 홈]] 노트를 현관문으로 두고, 주제마다 폴더 생성.
4. 노트는 [[📝 공부노트 템플릿]] 복사해서 시작 (또는 클로드에게 시킴).
5. 다 쓰면 [[🏠 홈]] 목록에 `[[새 노트]]` 링크 추가.
6. `[[` 로 노트끼리 부지런히 연결 → 그래프가 자란다.
